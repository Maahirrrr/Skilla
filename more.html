Tools, Connectors & Helpful Guides

Useful connectors, protocols, and honest answers to help make your agentic coding setup feel effortless.

Model Context Protocol (MCP) Connectors

Browserbase MCP

Gives autonomous agents live headless Chromium browsers to execute end-to-end visual QA and design audit playbooks.

npx -y @browserbase/mcp-server

GitHub & Git MCP

Allows skills like ECC and Impeccable to draft PRs, read AST commits, and synthesize clean patches directly.

npx -y @modelcontextprotocol/server-github

Figma Code Connect

Binds live Figma design token variables and vector component trees directly into agent context.

npx -y @figma/code-connect-mcp

Skilla Registry MCP

Allows your local agent to search, query, and hot-load all 1,400+ SKILL.md playbooks on the fly.

npx -y @skilla/mcp-server

Frequently Asked Questions

What is a SKILL.md file? +
A SKILL.md file is a standardized markdown document containing YAML frontmatter and domain-specific engineering playbooks. It instructs LLMs on design aesthetics, architecture constraints, and tool usage without requiring fine-tuning.
Which runtimes support Skilla playbooks? +
Skilla playbooks run out-of-the-box on Antigravity (Google DeepMind), Claude Code (Anthropic CLI), Cursor, Windsurf, Codex, and any agent supporting system prompt extensions or MCP tools.
How do skills prevent generic AI UI code? +
Skills like Taste, Impeccable, and Emil Kowalski enforce negative constraints: banning default Tailwind template styles, requiring custom fonts (e.g. Libre Caslon, Newsreader, Inter), demanding high contrast ratios, and mandating sub-stepped spring physics.
