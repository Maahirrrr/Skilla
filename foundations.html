# Operational Philosophy
When auditing or generating interfaces, avoid generic corporate AI templates:
- Use intentional, opinionated typography (pairing distinctive serif with high-legibility sans).
- Ensure high contrast ratios and purposeful negative space.
- Sub-step all fluid physics springs for continuous 60-120fps rendering.

## Step-by-Step Execution
1. Inspect DOM structure and inspect element hierarchy.
2. Verify token budgets and font rendering metrics.
3. Validate interactive hover, active, and focus states.
4. Run automated test pass and emit actionable diffs.
